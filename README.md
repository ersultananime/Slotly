# Slotly — ИИ-консультант для сайта компании

Slotly помогает бизнесу подготовить консультанта по своим услугам, ценам и контактам. Владелец регистрируется, указывает сайт или заполняет базу знаний вручную, проверяет описание и сохраняет его в личном кабинете.

Цель продукта — виджет, который консультирует посетителей сайта и собирает заявки. Сейчас реализованы лендинг, авторизация, личный кабинет и подготовка базы знаний. Внешний виджет ещё требует разработки.

[Репозиторий](https://github.com/ersultananime/Slotly)

## Возможности

- Регистрация и вход через Supabase Auth, подтверждение email и выход из аккаунта.
- Защищённый кабинет с данными компании текущего пользователя.
- Ручное редактирование и сохранение базы знаний — до 50 000 символов.
- Подготовка черновика по сайту: сбор до 5 HTML-страниц и обработка через Google Gemini.
- Просмотр источников и проверка черновика до сохранения. Анализ сам по себе не заменяет сохранённую базу знаний.
- Квота анализа в Supabase: не чаще одного раза в минуту, до 10 попыток в час на пользователя.
- Просмотр лидов компании с пагинацией, контактами, сообщениями и статусами.
- Формирование кода установки с идентификатором компании.
- Демонстрационный чат на лендинге.

## Текущий статус

В репозитории пока нет `public/widget.js`, на который ссылается код установки. Получение кода в кабинете ещё не означает готовность внешнего виджета.

`POST /api/chat` возвращает шаблонные ответы о Slotly. Он не вызывает OpenAI, не использует базу знаний компании и не сохраняет контакты в таблицу лидов. Отправка заявок в Telegram/CRM, перевод на оператора, биллинг и аналитика диалогов пока не реализованы. Упоминания этих функций на лендинге описывают направление продукта.

Анализ сайта читает доступный HTML, не исполняет JavaScript и не обрабатывает PDF или страницы за авторизацией. Результат нужно проверить перед сохранением.

## Локальный запуск

### 1. Установить зависимости

Нужны Node.js версии 20.9 или новее, npm и проект Supabase. Для анализа сайтов также нужен серверный ключ Google Gemini.

```bash
git clone https://github.com/ersultananime/Slotly.git
cd Slotly
npm ci
```

Команды выполняются из каталога с `package.json`.

### 2. Заполнить переменные окружения

Скопируйте `.env.example` в `.env.local`. В PowerShell:

```powershell
Copy-Item .env.example .env.local
```

В macOS/Linux: `cp .env.example .env.local`.

| Переменная | Назначение |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | URL проекта Supabase. Обязателен для авторизации и кабинета. |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Публичный anon-ключ того же проекта Supabase. |
| `GEMINI_API_KEY` | Серверный ключ Google Gemini для анализа сайтов. Без него доступно ручное заполнение базы знаний. |
| `GEMINI_WEBSITE_MODEL` | Модель анализа; по умолчанию `gemini-2.5-flash`. |
| `NEXT_PUBLIC_SITE_URL` | Необязательный адрес приложения для ссылок подтверждения email: локально `http://localhost:3000`, в production — домен приложения. |
| `DATABASE_URL`, `DIRECT_URL` | Подключения для Prisma и старой схемы онлайн-записи. Кабинет работает через Supabase-клиент; эти подключения не заменяют SQL-миграции кабинета. |

`NEXT_PUBLIC_SITE_URL` используется кодом, но пока отсутствует в `.env.example`: при необходимости добавьте его самостоятельно. Если он не задан, используется `NEXT_PUBLIC_VERCEL_URL`, затем origin браузера; серверный запасной адрес — `http://localhost:3000`.

Секреты храните в `.env.local` или переменных окружения хостинга. Не добавляйте их в Git. Для `GEMINI_API_KEY` нельзя использовать префикс `NEXT_PUBLIC_`.

### 3. Запустить приложение

```bash
npm run dev
```

Откройте [localhost:3000](http://localhost:3000), зарегистрируйтесь и перейдите в `/dashboard`. Сохраните описание вручную либо подготовьте черновик по сайту и проверьте его перед сохранением.

## Проверки и сборка

```bash
# Проверки URL, загрузки страниц, извлечения текста и ответов AI
npx tsx --test src/lib/website/website.test.ts

# Проверка типов
npx tsc --noEmit

# ESLint
npm run lint

# Production-сборка: prisma generate и next build
npm run build

# Запуск собранного приложения
npm start
```

Тесты анализа подменяют ответы Gemini и не требуют настоящего API-ключа. Для проверки регистрации, кабинета и анализа целиком нужен настроенный Supabase; для реального анализа — также ключ Gemini.

## Структура проекта

```text
src/
  app/
    page.tsx                     # Лендинг
    login/, register/            # Авторизация
    auth/callback/               # Обмен кода подтверждения на сессию
    dashboard/                   # Кабинет и редактор базы знаний
      analyze/                   # Серверный анализ сайта
      leads/                     # Просмотр лидов компании
    api/chat/                    # Демонстрационные ответы о Slotly
  lib/
    dashboard.ts                 # Проверка пользователя и компании
    supabase/                    # Клиенты Supabase
    website/                     # Сбор страниц, подготовка описания, тесты
    config.ts                    # Бренд, тариф и контакты
  proxy.ts                       # Обновление сессии и защита маршрутов
supabase/migrations/              # SQL-миграции текущего кабинета
prisma/                          # Схема и seed прежней версии онлайн-записи
public/                          # Логотипы и статические файлы
.env.example                     # Пример переменных окружения
```

Подробности анализа и его ограничений: [`docs/website-analysis.txt`](docs/website-analysis.txt).
