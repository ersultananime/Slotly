# Slotly — Сервис записи к мастеру

> Сайт-лендинг для мастеров красоты, которые хотят принимать записи от клиентов без переписки в директ.

---

## 📁 Структура проекта

```
Lead bot/
├── index.html       # Главная страница (лендинг)
├── booking.html     # Страница записи клиента к мастеру
└── README.md        # Описание проекта
```

---

## 📄 Файлы и что в них находится

### `index.html` — Главная страница (лендинг)

Это лицо сервиса Slotly. Предназначена для мастеров, которые хотят подключиться к сервису.

Страница разбита на следующие секции:

| Секция | ID / Класс | Описание |
|--------|-----------|----------|
| **Навигация** | `nav` | Логотип Slotly, ссылки на якоря (#pain, #how, #pricing) и кнопка «Открыть страницу записи» |
| **Hero (заглавный блок)** | `.hero` | Заголовок, подзаголовок, кнопки действия и визуальные карточки слотов (15:00, 17:30, 19:00) |
| **Проблема** | `#pain` | 4 карточки с описанием болей мастера: двойная запись, не пришедший клиент, переписка в директ, непрозрачный доход |
| **Как это работает** | `#how` | 3 шага подключения: настройка расписания → ссылка в Instagram → клиент записывается сам |
| **Цена** | `#pricing` | Один тариф — 3 900 ₸/месяц, первый месяц бесплатно. Список возможностей |
| **Финальный CTA** | `#demo` | Призыв посмотреть пример страницы записи, кнопка перехода на `booking.html` |
| **Footer** | `footer` | Логотип Zapis |

---

### `booking.html` — Страница записи клиента

Это страница, которую видит **клиент мастера** — по личной ссылке вида `zapis.kz/имя_мастера`. Дизайн адаптирован под мобильный экран (максимальная ширина 460px).

Страница разбита на следующие блоки:

| Блок | Класс | Описание |
|------|-------|----------|
| **Профиль мастера** | `.profile` | Аватар, имя мастера (Айгерим Нурланова), специализация и бейдж «Есть места на этой неделе» |
| **Выбор услуги** | `.section` (первый) | Список услуг с ценой и длительностью: Маникюр (8 000 ₸ / 90 мин), Педикюр (7 000 ₸ / 60 мин), Наращивание (14 000 ₸ / 150 мин) |
| **Выбор даты** | `.section` (второй) | Горизонтальная полоса с датами (чт–вт) и сетка доступных слотов времени (занятые помечены отдельно) |
| **Контакты клиента** | `.section` (третий) | Форма с двумя полями: Имя и WhatsApp номер |
| **Итог записи** | `.summary` | Тёмная карточка с итогом: услуга, дата/время, сумма |
| **Кнопка подтверждения** | `.cta-wrap` | Кнопка «Записаться» + подпись о WhatsApp-уведомлении |
| **Footer** | `.footer-brand` | Ссылка обратно на `index.html` |

## 🎨 Дизайн-система

Весь CSS написан в одном файле внутри каждого HTML (тег `<style>`), без внешних CSS-файлов.

### Цветовая палитра

| Переменная | Значение | Применение |
|-----------|---------|-----------|
| `--ink` | `#211B1C` | Основной цвет текста |
| `--ink-soft` | `#5B5254` | Вторичный текст |
| `--paper` | `#FBF4EF` | Фон страницы |
| `--paper-raised` | `#FFFFFF` | Фон карточек |
| `--coral` | `#E2704F` | Акцентный цвет, кнопки CTA |
| `--coral-deep` | `#C4552F` | Hover-состояние кнопок |
| `--pine` | `#2E5546` | Финальный CTA блок |
| `--pine-soft` | `#E8F0EA` | Фон финального блока |
| `--sand` | `#D9BD93` | Декоративные элементы |
| `--line` | `#E7DBD0` | Разделители, бордеры |

### Типографика

- **Заголовки** — `Fraunces` (serif, Google Fonts)
- **Основной текст** — `Inter` (sans-serif, Google Fonts)

## 📱 Адаптивность

| Файл | Брейкпоинт | Изменения на мобильном |
|------|-----------|------------------------|
| `index.html` | `max-width: 860px` | Скрывается навигация, hero-блок становится одноколоночным, шаги и карточки перестраиваются вертикально |
| `booking.html` | Изначально мобильный дизайн | Фиксированная ширина 460px, оптимизировано под телефон |

---

## 🚀 Как открыть локально

1. Скачайте или клонируйте репозиторий
2. Откройте `index.html` в браузере — это главная страница
3. Нажмите кнопку **«Открыть пример страницы записи →»** или откройте `booking.html` напрямую

> Никаких зависимостей и сборщиков не требуется — чистый HTML + CSS.
